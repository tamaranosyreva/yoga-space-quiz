# Подбор практики Yoga Space

Прототип теста для новых гостей и материалы к нему — в одном файле `index.html` с тремя вкладками:

1. **Схема подбора** — как работает тест (для руководства).
2. **Логика подбора** — дерево решений, правила и таблица «кто что получает».
3. **Подбор практики** — сам тест.

Прямые ссылки на вкладки: `index.html#scheme`, `index.html#logic`, `index.html#quiz`.

Расписание в тесте — снимок недели 19–25 октября 2026 года, для примера.

## Как обновить

Файл собирается скриптами из папки `Тест для новичков/scripts`:

```bash
python3 build_quiz.py && python3 build_scheme.py && python3 build_logic_report.py && python3 build_site.py
```

## Как открыть на GitHub Pages

Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)`. Через минуту сайт будет доступен по адресу `https://<аккаунт>.github.io/<репозиторий>/`.
